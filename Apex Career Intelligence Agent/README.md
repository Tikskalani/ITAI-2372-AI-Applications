## What Is APEX?

APEX is a **local AI agent** that turns resume optimization from a static document exercise into a complete career intelligence system. 

Every other resume tool (Jobscan, Rezi, Teal, Resume.io) works the same way: score your resume against a keyword database, tell you what's missing, charge you $29-49/month. APEX does something fundamentally different.

**APEX scrapes live job postings in real-time**, runs a self-graded 3-iteration improvement loop, and populates **16 analysis tabs simultaneously** — all from a single click, for approximately 18 cents per run.

## Architecture

### Backend — `agent_server.py` (1,769 lines)

```
ThreadingHTTPServer — port 7842
├── /analyze    → Full 8-phase agent loop
├── /drift      → Market drift detection
├── /match      → Smart job match scorer  
├── /tailor     → Job-specific resume rewriter
├── /bullets    → Bullet strength ranker
├── /negotiate  → Salary negotiation brief
├── /bridge     → Skills bridge (career change)
├── /xray       → Weakness X-Ray
├── /velocity   → Career velocity score
└── /health     → Server health check
```

**Phase 8 — Parallel Generation**
After the main optimization loop, 5 generators fire simultaneously in separate threads:
```
gen_cover_letter() ─┐
gen_interview()    ─┤
gen_linkedin()     ─┼─ all run in parallel → all 16 tabs populate
gen_outreach()     ─┤
gen_velocity()     ─┘
```

**No pip packages required.** Pure Python 3.8+ stdlib: `http.server`, `urllib`, `json`, `threading`, `xml.etree`.

### Frontend — `index.html` (1,300 lines)

- **Zero framework** — Vanilla HTML/CSS/JavaScript
- **Fonts**: Bebas Neue (display) + Outfit (UI) + JetBrains Mono (code/resume)  
- **Design**: Pure black canvas, electric indigo → phosphor cyan gradients, animated orbs, grain texture, CRT scanlines
- **Layout**: CSS Grid, 16-tab navigation, responsive sidebar
- **Storage**: localStorage for version history, application tracker, and persistent state
- **File upload**: pdf.js + mammoth.js loaded on-demand (no bundling)
- **Streaming**: EventSource SSE — real-time agent log appears as the agent runs

## Getting Started

### Prerequisites

- Python 3.8 or higher
- OpenAI API key — [get one here](https://platform.openai.com/api-keys)
- JSearch API key (free tier available) — [get one here](https://rapidapi.com/letscrape-6bRBa3QguO5/api/jsearch)

### Setup

```bash
# 1. Clone the repo
git clone https://github.com/YOUR_USERNAME/apex-career-intelligence.git
cd apex-career-intelligence

# 2. Create your config file (never commit this)
cp config.example.json config.json

# 3. Add your API keys to config.json
# Edit config.json and replace the placeholder values:
# {
#   "OPENAI_KEY": "sk-proj-...",
#   "JSEARCH_KEY": "..."
# }

# 4. Start the agent server
python agent_server.py

# 5. Open index.html in your browser
# On Mac:
open index.html
# On Windows:
start index.html
# On Linux:
xdg-open index.html
```

That's it. No `npm install`. No `pip install`. No Docker. No config beyond two API keys.

### First Run

1. Enter your target job title (e.g. "Regional Property Manager")
2. Select your industry and seniority level
3. Upload your resume (PDF/DOCX/TXT) or paste the text
4. Optionally paste a specific job description for higher precision
5. Click **LAUNCH AGENT**
6. Watch all 16 tabs populate in real time

## How the Self-Improvement Loop Works

This is the core innovation that no competitor has built:

```
Baseline Resume
      │
      ▼
Iteration 1: Inject all validated market keywords naturally
      │  Score improved? → KEEP this version
      ▼
Iteration 2: Quantify every achievement (add metrics)  
      │  Score improved? → KEEP · Score regressed? → REVERT to iter 1
      ▼
Iteration 3: Improve readability and flow
      │  Score improved? → KEEP · Same/worse? → Keep best previous
      ▼
Final Resume (highest-scoring iteration, validated by the model itself)
```

Other tools optimize once and stop — with no way to know if the output is better or worse. APEX validates every change against the market data and only keeps improvements.

## Market Drift Detection

After your first optimization run, APEX saves your ATS score to `localStorage`. Every time you open the app (with a 7-day minimum interval), it re-scrapes live job postings for your saved role and compares the current keyword match against your baseline.

If your score has drifted more than 8 points due to market changes (new tools becoming standard, old keywords falling out of favor), a warning banner appears with the specific new keywords — and a one-click button to re-optimize.

Your resume should never go stale without you knowing.
